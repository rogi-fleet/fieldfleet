Built for field work

One workspace from lead to closeout

FieldFleet brings the job lifecycle into one self-hostable codebase: customer records, job setup, crew coordination, document generation, field data capture, and reporting.

01

Projects and scheduling

Project health, Gantt planning, baselines, calendars, task dependencies, and capacity planning.

02

CRM and portals

Customers, vendors, opportunities, custom fields, and dedicated client, vendor, and employee portals.

03

Financial workflows

Budgets, cost catalogs, estimates, invoices, payment links, subcontracts, bid packages, and holdbacks.

04

Field operations

Dynamic forms, e-signing, time tracking, inventory, vehicles, assets, maintenance, and QR workflows.

05

Documents and files

Templates, PDF output, spec books, spec sheets, file folders, photo markup, and document activity.

06

AI-assisted workflows

AI copilot, text operations, daily summaries, and an MCP endpoint for agent integrations.

Self-hostable

Run FieldFleet locally

The public checkout uses an isolated Supabase project id and ports so it can run next to another local Supabase stack. 

flutter pub get
supabase start
supabase migration up --local
scripts/create_local_demo_user.sh
flutter run -d chrome \
  --dart-define=SUPABASE_ANON_KEY=your-local-supabase-anon-key
